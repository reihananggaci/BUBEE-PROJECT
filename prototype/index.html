DOKUMENTASI DESAIN & PROTOTYPE

Proyek Web Programming 3 (WP3) - Bubee Distributor

📋 Data Pengumpulan Proyek:
Nama Aplikasi: Bubee Tumbler Distributor
Mata Kuliah: Web Programming 3 (WP3)
Tech Stack: Laravel 11, Tailwind CSS, SQLite/MySQL
Role Akses: Admin Gudang, Mitra Reseller, User Reguler

🎯 Fitur & Inovasi Desain yang Diimplementasikan:

  • Penggabungan Produk Multi-Kapasitas (270mL - 1000mL):

    Mengurangi penumpukan katalog dengan menggabungkan varian ukuran botol yang sejenis ke dalam 1 produk dengan tombol pilihan kapasitas interaktif.

  • Keamanan Cloudflare Turnstile Captcha:

    Proteksi login tanpa membuat pengguna pusing dengan puzzle, didukung Mode Demo Always-Pass untuk lingkungan pengujian.

  • Pemisahan Tab & Paginasi Panah ke Samping:

    Daftar produk admin dibagi menjadi Tabel Ringkasan dan Kartu Kelola, serta paginasi panah samping `[← Sebelumnya] [Berikutnya →]` agar tidak memanjang ke bawah.

  • Saklar Status ON / OFF Langsung:

    Admin dapat menonaktifkan dan mengaktifkan barang secara instan tanpa perlu masuk ke form edit.

  • Laporan Filter Fleksibel:

    Mitra dan Admin dapat menyaring omzet secara Harian, Mingguan, dan Bulanan.
