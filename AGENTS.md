# Aturan Pengembangan Project Bubee

## 1. Otomatisasi GitHub Push
Setiap kali melakukan penambahan, pengubahan, atau perbaikan kode/skrip pada project ini:
- Selalu lakukan commit dan push ke remote repository GitHub (`git@github.com:reihananggaci/BUBEE-PROJECT.git`) pada branch `main`.
- Gunakan pesan commit yang jelas dan deskriptif (`fix: ...`, `feat: ...`, `chore: ...`).
- Pastikan perintah `git push origin main` berhasil dijalankan sebelum mengakhiri giliran/tugas.
